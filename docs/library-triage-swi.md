# Library triage — SWI-Prolog

Which of SWI's bundled libraries load on Shumway today, and what each one that
does not needs. Generated by loading every `<swi>/library/*.pl` with
`use_module(library(X))` under the `swi` dialect (ADR-040) and recording the
outcome. Re-run with the opt-in `Shumway.Tests.DialectInterop` project.

**Snapshot: 46 of 129 load cleanly.** SWI uses more system-specific syntax and
directives than Scryer, so more remains — but the blockers cluster, so a few
targeted features unblock many libraries at once.

## Loads cleanly (46)

INDEX, aggregate, assoc, base32, broadcast, coinduction, ctypes, date, dialect,
dif, fastrw, files, gensym, heaps, hotfix, increval, intercept, lists,
nb_rbtrees, obfuscate, occurs, option, oset, pairs, portray_text, prolog_code,
prolog_config, prolog_debug, prolog_evaluable, prolog_format, prolog_jiti,
prolog_wrap, quasi_quotations, quintus, readln, sort, streams, system, tables,
ugraphs, utf8, varnumbers, vm, when, writef, yall.

(`assoc` = AVL trees, needed meta_predicate + autoload + `=>` SSU + `:- if/else`;
it now loads. `yall` = `[X]>>Goal` lambdas. `aggregate`, `heaps`, `sort`, …
substantial pure libraries.)

## Blockers cluster — ranked by libraries unblocked

### 1. `=@=` / `\=@=` operators — ~24 libraries (BIGGEST WIN)

24 PARSE failures are `Expected RParen, got Atom '=@='` — the variant / structural
equivalence operators SWI defines (`op(700, xfx, =@=)`, `op(700, xfx, \=@=)`) but
Shumway does not. Adding the two operators (and the `=@=/2` / `\=@=/2` predicates
— variant check, we can implement) unblocks the parse of ~24 libraries in one go.

### 2. `:- if` condition evaluator gaps — ~6 libraries

Several OTHER failures are `unsupported :- if/elif condition` for
`exists_source(library(X))` and `current_prolog_flag(F, V)` — the conditional-
compilation evaluator (just shipped) does not handle these two condition forms
yet. Adding them (exists_source → resolve on the search path; current_prolog_flag
→ read the flag) unblocks: `edit`, `explain`, `iostream`, `modules`,
`console_input`, `win_menu`.

### 3. Directive no-ops — ~10 libraries

MISSING existence_errors for SWI declaration directives that are safe no-ops for
us (same pattern as `:- meta_predicate` / `:- autoload`):
`predicate_options/3` (5), `module_transparent/1` (2), `module_property/2` (3,
also a real predicate), `create_prolog_flag/3` (2), `current_arithmetic_function/1`
(2), `reexport/1`, `redefine_system_predicate/1`, `det/1`, `at_halt/1`, `$hide/1`,
`format_predicate/2`, `encoding/1`. Most become recognised no-op directives;
a few (`module_property`, `must_be`, `print_message`) are real predicates worth a
small Prolog/C# shim.

### 4. String escapes `\e` / `\c` — ~3 libraries

`Unknown escape sequence '\e'` (escape char, 0x1B) and `'\c'` (line-continuation:
`\c` at end of line consumes the following whitespace). Both are lexer additions.

### 5. Real predicates — a handful

`must_be/2` (error library — have partial), `print_message/2` (message system —
larger), `reexport/1` (module re-export).

## Structural / larger features (defer)

- **SWI dicts `{...}` / `Tag{...}`** — several `Expected '.' after clause, got
  LBrace '{'` and `got Atom '.'` (dict field access `X.field`). SWI dicts are a
  language feature (a real project), not a shim.
- **`:- table foo as (incremental|...)`** — the `as` tabling options
  (`got Atom 'as'`). Tabling-options syntax.
- **Threads** — any library over `library(thread)` / `thread_create` etc. is
  structurally incompatible until Shumway has a thread model (none surfaced as a
  top-level load failure here, but thread-using libraries would).
- **Foreign C predicates** — libraries fronting a C extension (`socket`, `ssl`,
  `sgml`, `http` transport) need the native backend, not a Prolog shim.

## Suggested order of attack (by impact)

1. **`=@=` / `\=@=` operators + predicates** → ~24 libraries. One operator pair +
   a variant-check predicate.
2. **`exists_source/1` + `current_prolog_flag/2` in the `:- if` evaluator** → ~6.
3. **Directive no-ops** (`predicate_options`, `module_transparent`, …) → ~10.
4. **`\e` / `\c` lexer escapes** → ~3.
5. Real predicates (`module_property`, `must_be`, `print_message`), then the
   structural items (dicts, threads, foreign) as their own arcs.
