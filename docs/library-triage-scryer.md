# Library triage — Scryer Prolog

Which of Scryer's bundled libraries load on Shumway today, and what each one that
does not needs. Generated by loading every `C:/Scryer/lib/*.pl` with
`use_module(library(X))` under the `scryer` dialect (ADR-040) and recording the
outcome. Re-run with the opt-in `Shumway.Tests.DialectInterop` project.

**Snapshot: 41 of 46 load cleanly.** Scryer is close to fully supported — the
attributed-variable / SSU / conditional-compilation work already landed covers
almost everything.

## Loads cleanly (41)

arithmetic, assoc, atts, between, charsio, clpb, clpz, cont, csv, dcgs, debug,
diag, dif, error, files, format, freeze, gensym, iso_ext, lambda, lists,
ops_and_meta_predicates, ordsets, os, pairs, pio, process, queues, random, reif,
sgml, si, sockets, tabling, terms, time, tls, ugraphs, wasm, when, xpath.

(`clpz`, `clpb`, `reif`, `dif`, `freeze` exercise the attribute machinery;
`dcgs`/`format` the DCG + format shims; `tabling` tabling.)

## Needs a small shim (4)

| library | blocker | what it needs | notes |
|---|---|---|---|
| `crypto` | `existence_error($is_partial_string/1)` | a `$is_partial_string/1` builtin (C#) | the `.pl` also fronts real crypto — the pure part may work with the stub; full function needs a crypto backend (structural) |
| `ffi` | `existence_error($is_partial_string/1)` | same builtin | FFI to C is **structurally** a native-interop concern (Shumway has `:- native`, ADR-024) — the `.pl` layer may load, the actual FFI is separate |
| `uuid` | `existence_error($is_partial_string/1)` | same builtin | likely loads with the builtin; UUID generation may need a source of randomness/time (have it) |

**One builtin (`$is_partial_string/1`) unblocks the parse/load of all three.**
It tests whether a term is a partial string (PSTR) — Shumway has PSTR cells, so a
C# builtin is straightforward.

## Parse / structure issues (2 — investigate)

| library | error | note |
|---|---|---|
| `builtins` | `1424:59: Unexpected Bar '|'` | a `|` where a term was expected — reader edge case; investigate the exact construct |
| `simplex` | `Clauses for ,/4 are not contiguous` | clauses grouping under `,/4` — likely an operator/quoting shape the reader mis-splits; investigate |

## Structurally incompatible

None found outright. `ffi`/`crypto` need native backends for their full function
(the `.pl` shim aside), which is the `:- native` / foreign-interop story, not a
Prolog-level shim.

## Suggested order of attack

1. `$is_partial_string/1` builtin → `crypto`/`ffi`/`uuid` parse+load (3 libs, one small C# builtin).
2. `builtins` `|` reader edge case.
3. `simplex` `,/4` grouping.
